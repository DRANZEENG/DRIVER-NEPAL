# Driver Nepal — starter demo

यो Android/Web का लागि Flutter starter project हो।

## GitHub मा राख्ने तरिका
ZIP extract गरेर ZIP भित्रका सबै फाइल र फोल्डरलाई GitHub repository को root मा upload गर्नुहोस्। ZIP फाइल मात्र upload नगर्नुहोस्।

कम्तीमा `pubspec.yaml`, `lib/`, `web/`, र `.github/workflows/build.yml` repository root मा देखिनुपर्छ।

## APK
GitHub को Actions मा `Build Driver Nepal APK` workflow चलाउनुहोस्। सफल भएपछि run को Artifacts भागबाट `Driver-Nepal-APK` डाउनलोड गर्नुहोस्।

यो प्रारम्भिक demo मात्र हो; login, database, वास्तविक vacancy र सुरक्षित admin सेवा समावेश छैनन्।
